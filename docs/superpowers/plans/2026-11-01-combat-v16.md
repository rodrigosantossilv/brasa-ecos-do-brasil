# BRASA 0.16 — execução das melhorias do combate

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Entregar melhorias reais de controle, animação e inspeção para todos os76 lutadores, com pacote Windows e publicação no GitHub.
**Architecture:** Continuar JavaScript/Canvas e o acumulador60 Hz. Introduzir módulos de dados de ataque, input e ferramentas de treino; migrar por compatibilidade antes de tuning. Preservar identidades, histórias, arenas e comandos simples.
**Tech Stack:** Node24, JavaScript browser, Canvas2D, testes VM/nativeCanvas existentes.
**Spec:** `docs/combat-phase-2-plan.md` e autorização do usuário para aplicar as mudanças ao jogo inteiro.

## Global Constraints

- Simulação60 Hz, controles PS4/PS5/Xbox e teclado, funcionamento offline.
- Não apagar progresso nem substituir a identidade do elenco. Nenhuma voz narradora.
- Todos os76 kits usam os novos contratos; especiais continuam nos botões diretos.
- Não declarar arte, fluidêz no hardware ou parry concluídos sem validar.

## Review Focus

- Input durante hitstop/catch-up/pause não se perde nem repete.
- Mudança de facing não transforma direção antiga em motion novo.
- Contatos simultâneos, armor, reflection e caps de dano permanecem corretos.
- Caixas de debug e poses usam o mesmo sistema de coordenadas/escala.
- Reset/step em treino não altera desbloqueios, resultado ou outra partida.
