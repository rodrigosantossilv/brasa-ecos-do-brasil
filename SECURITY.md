# Segurança

Não publique tokens, senhas ou dados pessoais em issues ou commits. Para relatar uma falha sensível, use o contato privado do mantenedor no GitHub ou o relato privado de vulnerabilidade, quando habilitado. Inclua versão, impacto e reprodução mínima, sem credenciais reais.

O jogo usa armazenamento local para opções e progresso. O launcher preserva o perfil e verifica os recursos por SHA-256. Atualizações devem ser obtidas do mantenedor.
